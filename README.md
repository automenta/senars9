# SeNARS

This repository contains the SeNARS project, a system for real-time AI reasoning. The project is divided into two main components:

- `core`: The main reasoning engine and WebSocket server.
- `ui`: A graphical user interface for interacting with the `core`.

## Running the Project

To run the `core` server, navigate to the `core` directory and use the following command:

```bash
cargo run --bin server
```

To run the `ui`, navigate to the `ui` directory and use the following command:

```bash
cargo run
```
